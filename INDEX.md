# INDEX: куда идти

Учебное приложение по книге Берна «Игры, в которые играют люди»: конспекты, тесты, карточки.
Статика без сборки. Выложено на GitHub Pages: https://envilope1337.github.io/bern/

| Вопрос | Куда |
|---|---|
| Добавить главу, поменять оглавление | `content/book.js` и список файлов `content/files.js` |
| Текст главы: конспект, тест, письменные вопросы, карточки | `content/<id>.js`, образец `content/ch2.js` |
| Тест по разделу | `content/part1.js` |
| Экраны, тест, карточки, расписание повторений, схемы | `app.js` |
| Цвета, шрифты, вёрстка | `styles.css` |
| Работа без сети | `sw.js` |
| Имя и иконка на главном экране телефона | `manifest.webmanifest`, `icons/` |
| План работ по всем главам первой книги, отметки о сделанном | `docs/plans/2026-11-15-pervaya-kniga.md` |
| Оглавление издания, id глав, игры по главам | `docs/toc.md` |
| Термины издания, названия игр, рисунки, которые расходятся с текстом | `docs/glossary.md` |
| Разрезать файл книги на главы в `source/` (в git не попадает) | `tools/split_book.py` |
| Проверить материал: тесты, id, термины, списанное из книги | `tools/check-content.js` |
| Сверить с ключом ответы агента, решавшего тест без книги | `tools/grade-nobook.js` |
| Сквозной сценарий на 375 и 1440, работа без сети | `tools/check_app.py` |
